# Login_j3xdr

Admin back-office for CKR WWDC tokens.

- Admin UI: https://j3xdr.github.io/Login_j3xdr/
- Public farm UI: https://j3xdr.github.io/CKR-WWDC/
- API: https://ckr-wwdc.onrender.com/

**Only this site** creates users and credits tokens (username + password + initial tokens).

## Local

Open `index.html` in a browser, or use GitHub Pages (branch root).
